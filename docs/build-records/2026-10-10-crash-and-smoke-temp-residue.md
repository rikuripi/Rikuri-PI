## Limitations

- A scratch home goes into the wrapper's `TMPDIR` only while that path stays short (at most 61 bytes; it is 24). If the wrapper's directory grew past that, both harnesses would fall back to `/tmp`, out of the check. The smoke self-test runs smoke through the real wrapper and requires the home inside its `TMPDIR`, so that fallback fails the gate's self-tests; the crash-matrix test only pins the wrapper's current shape, but its harness follows the same 42-byte rule.
- If the wrapper itself is killed, its own cleanup does not run and `/tmp/rikuri-tests.*` stays; no in-process cleanup survives SIGKILL.
- The shell rule is textual: smoke strips one trailing slash and knows the root only as `/` or `//`. Given `TMPDIR=///`, `////` or `/.`, it tries the root and fails loudly (nothing left), where the crash matrix, comparing paths, uses `/tmp`.
