# Parking lot

The planning baseline is frozen for Foundation-0 execution ([ADR 0000, September 28 review follow-ups](../doc/Rikuri_Pi_ADR_0000_Foundation0_Scope_Reconciliation.md#september-28-2026--option-c-review-follow-ups-and-foundation-0-credential-scope)). New ideas, features and speculative redesigns are written here instead of into the PRD, Architecture or Stage Plan.

An entry here is not a commitment, a requirement or a schedule. It carries no gate and needs no test.

**What does not belong here:** a discovered error in a requirement, a security claim or a runbook. Those are corrected through a dated ADR with matching tests (Stage Plan > Stop-the-line rules and document control).

**Leaving the lot:** an entry becomes work only through the Master Build Sequence deferral/resequencing protocol, which names its stage, predecessor gates, owner and acceptance. Review the lot when the Master Build Sequence is reordered from Foundation evidence (S05.10), before post-Foundation stages are re-estimated.
